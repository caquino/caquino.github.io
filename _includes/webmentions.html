{%- comment -%} Webmentions via webmention.io. Fetches replies, likes, reposts for the current post URL from the public JF2 API and renders them inline. Requires a one-time sign-up at https://webmention.io/ with GitHub auth, which produces your receiver endpoint. Set in _config.yml: webmention_endpoint: https://webmention.io/syshero.org/webmention webmention_pingback: https://webmention.io/syshero.org/xmlrpc The in head.html advertises the endpoint so other sites (Bridgy, Mastodon via brid.gy, dev.to cross-posts) can deliver mentions. Reads are unauthenticated and work out of the box. {%- endcomment -%} {%- if site.webmention_endpoint -%}
